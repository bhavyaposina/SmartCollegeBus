# 🚌 Smart College Bus Tracking & Seat Availability

## 📌 Project Overview
Smart College Bus Tracking & Seat Availability is an Android application designed to help students view college bus details, check available seats, reserve seats, and follow a simulated bus route.

The application provides a simple interface for managing bus information and seat bookings.

## 🎯 Objectives
- Display college bus routes and departure timings.
- Show seat availability for each bus.
- Allow students to select and book seats.
- Save bookings locally on the device.
- Display previously booked seats.
- Demonstrate bus movement through simulated tracking.

## ✨ Features
- **Home Screen:** Easy navigation between app features.
- **Bus List:** Displays three sample buses and their timings.
- **Seat Booking:** Interactive 40-seat layout for each bus.
- **Seat Availability:** Updates available-seat counts after bookings.
- **My Bookings:** Displays saved bookings for each bus.
- **Bus Tracking:** Simulates movement through predefined route stops.

## 🛠️ Technologies Used

- Java
- XML
- SharedPreferences for local data storage

## ⚙️ How to Run
1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle synchronization to complete.
4. Run the application on an Android emulator or compatible device.

## ⚠️ Limitations
- Bus details and routes are sample data.
- Tracking is simulated; it does not show a real bus's live GPS location.
- Bookings are stored locally and are not synchronized across multiple devices.
- No central server or administrator dashboard is included.
